# Console Expense Tracker

A small command-line app for keeping track of everyday spending. Add an expense with its date, category, and amount, review the expenses entered during the current session, or see how much you have spent in total.

## Requirements

- Python 3

## Run the app

Open a terminal in this folder and run:

```bash
python Expense_Tracker.py
```

On some systems, use `python3` instead of `python`.

## Menu options

1. **Add Expense** — enter a date, category, and amount.
2. **View All Expenses** — list expenses added since the app started.
3. **View Total Spending** — calculate the total of those expenses.
4. **Exit** — close the app.

When adding an expense, enter the date as `DD-MM-YYYY`, then provide a category (such as food, clothes, studies, or travel) and the amount spent.
